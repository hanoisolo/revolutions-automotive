   - Geo-coordinates: `43.7196, -79.7946` (latitude/longitude)

   - Telephone: (905) 846-8351
   - Opening hours specification (Mon–Fri 08:00–18:00, Sat 08:30–15:00,
     Sun closed)
   - Catalog service list derived from the 12 `SERVICE_CATALOG` entries.
   Define the exact nested schema (required/optional properties).

**New pure functions (exact contracts required in the roadmap):**

1. `parseTireSize(sizeStr)` — parses metric tire size strings (e.g.
   `"205/55R16"`, `"225/45R17"`, `"275/65R18"`) into
   `{ width, aspectRatio, rimDiameter, sidewallHeightMm,
      overallDiameterMm, overallDiameterInches, circumferenceMm }`.
   Returns `null` on invalid formats. Specify the exact regex, accepted
   formats/units, rounding rules, and the circumference formula
   (pi x overallDiameterMm).
2. `compareTireSizes(currentSizeStr, targetSizeStr)` — returns a comparison
   object containing diameter difference (mm and %), sidewall difference,
   speedometer reading at an actual 100 km/h, and a compliance rating:
   `"safe"` if the diameter difference is within ±3.0%, `"caution"`
   if greater than 3.0%. Returns `null` when either size is invalid.
   Specify the exact speedometer variance formula and rounding rules.
3. `generateVoucherData(estimatePayload, bookingPayload)` — returns a
   structured printable voucher payload with a **30-day rolling
   expiration date**, a formatted alphanumeric voucher code
   (`REV-VOUCH-XXXX`), a Midas-style disclaimer, and itemized
   subtotal / HST (13%) / total lines. Specify the exact output schema,
   code-generation determinism rules, and expiration date computation
   (testable, no raw `Date.now()` inside the assertion path).
4. `exportBookingsToCsv(bookingsArray)` — converts the work orders and
   bookings array into a clean, downloadable **RFC-4180 compliant** CSV
   string with headers. Specify the exact column set, quoting/escaping
   rules (embedded commas, quotes, newlines), and CRLF line endings.
5. `validateOwnerPin(enteredPin, currentPin)` — trimmed (constant-time
   preferred) PIN verification against the default `8351` or a configured
   PIN. Specify exact trimming, length, and comparison rules and the
   boolean return contract.
